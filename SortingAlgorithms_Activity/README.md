ang purpose sa akong java program kay sorting so naay 3 sa sort which is Bubble sort, selection sort, and insertion sort kana sila kay mag arrange sa value in order or mag sort sa lowest to highest

2.Bubble sort

Ang bubble sort kay ga swap each value so if ang index 0 na value kay dako sa index 1 kay mag swap sila, aron mabutang sa pinaka tumoy ang pinaka dako na value, then mag padayun ang loop hangtod ma sort na ang array in an ascending order.

3.Selection sort

Ang Selection Sort mag sugod siya og basa sa index 0 paingon sa last na index. Ang iyang buhaton kay mag check or mag scan siya og pinaka gamay na value, then mag-mark siya and mag hold sa lowest value nga iyang nakita. Mag padayon siya og check kung naa pa bay mas lowest na value. Kung wala na, i-swap niya ang lowest value sa pinaka-una na pwesto sa array. Mag-padayon dayon siya og loop sugod sa sunod na index, hangtod ma-sort na tanan value in ascending order.

4.Insertion sort

Ang insertion sort kay mag check sya sa pinaka una na array, mag sugod na dayun syag scan paingon sa last array but ang insertion sort is that mag stop sya marking the lowest value then continue scanning, if wala nay mas lowest kay iyang i pull ang value paingon sa pinaka lowest na array or value then iserting the value in the first index or the second highest to that lowest value then mag continue ang pag loop hangtud ma insert na tanan lowest to highest value.

5.Discuss the differences between the three sorting algorithms.

Ang bubble sort kay simplier sa 3 since mag swap ka sa duha ka value by comparing them pero mag lisud ang bubble sort if daghan ang data. Then, ang Selection Sort kay mag check siya og value, pero ang iyang pag check kay i hold niya ang lowest value hangtod mahuman siya og scan sa nahabilin na array. Kung nahuman na siya og scan, i swap niya ang lowest value sa pinaka una na pwesto sa wala pa na sort na parte. Meanwhile, ang insertion sort kay iyang i-scan tanan value, lowest to highest, but ang iyang pag-sort kay i-pull niya ang pinaka-lowest na value paingon sa first array, then inserting it.
